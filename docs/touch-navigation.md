# Touch Navigation

This guide covers the touchscreen shortcuts available from the **Lyra**,
**Dashboard**, and **Minimal** Home screens. These themes use the same gestures
when they show one recent-book cover.

The **BookOrbit** theme has its own gestures: see
[BookOrbit Home](./reader-features.md#bookorbit-home).

## Home-screen shortcuts

Start each swipe on the main part of the Home screen and move your finger in
the indicated direction. The following swipe gestures do not need to start at the edge of the screen to be recognized.

| Gesture         | Opens            |
| --------------- | ---------------- |
| Swipe **down**  | **Settings**     |
| Swipe **right** | **Browse Files** |
| Swipe **up**    | **Home menu**    |
| Swipe **left**  | **Next recent book** |
| Tap book cover  | Book             |

On X4 Pro, keep a down-swipe for Settings away from the very top edge. A
top-edge down-swipe opens the frontlight panel instead, but you can also access settings by tapping the settings icon in that panel.

### Swipe down to open Settings

Swipe down from Home to access global device settings.

### Swipe right to open the File Browser

Swipe right to open the SD-card file browser. Tap a folder to open it and tap
a book to start reading it. Tap and hold to open the context menu. Use the back arrow or swipe right from the left edge to move up a folder or return to Home.

### Swipe up for the Home menu

Swipe up to reveal shortcuts for Library, OPDS Browser, Bookmarks &
Clippings, Reading Stats, and File Transfer. Tap an item to open it; tap
outside the panel to close the menu.

### Swipe left to switch recent books

When at least two books are in your recent reading history, swipe left anywhere
on a one-cover Lyra, Dashboard, or Minimal Home screen to switch to the other
recent book.

## Cover Grid Home

On PSRAM devices such as Sticky and X4 Pro, choose **Settings > Display > UI
Theme > Cover Grid** for a Home screen with the current book and up to six
additional covers. Tap a cover to open its book. This is a separate Home theme
from Library's **Recently Opened View** grid option.

## Other touch navigation

- Tap a visible button, row, folder, or book to select it.
- In long lists, swipe up or down to move through the list.
- Swipe right from the left edge, or use the on-screen back arrow when shown,
  to go back from most screens.
- Reader-specific page-turn and menu gestures are documented in
  [Touch Reader Controls](./user-guide.md#touch-reader-controls).
